# tiny-chess-01

A 4 KB Python chess engine: 0x88 board, alpha-beta with iterative deepening
to a fixed 50,000-node budget, quiescence search, transposition table,
MVV-LVA + killer + history move ordering, and a material + piece-square
evaluation with bishop-pair and endgame-king terms. It plays the make.fun
gauntlet through the env at `MAKEFUN_ENV_URL` — run it with
`MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py`.
